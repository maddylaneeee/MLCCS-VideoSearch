# Retained diagnostics prototype

This directory preserves pre-v1 diagnostic upload and website-plugin source for historical reference only.
It is intentionally excluded from the solution, build, tests, installer, SBOM, product UI, IPC surface,
documentation promises, and release payloads. MLCCS Video Search v1.0.0 performs no telemetry or diagnostic
network requests. The supported product behavior is local redacted logging plus opening the local log folder.
