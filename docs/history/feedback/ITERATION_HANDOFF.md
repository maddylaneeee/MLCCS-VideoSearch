# MLCCS Video Search 0.3.0 Feedback 5 迭代交接

## 从零开始

1. 使用目录 `C:\Users\mattl\Downloads\1213`。
2. 双击根目录的 `Start-MLCCS-VideoSearch.cmd`。
3. 首次运行按向导选择内容类型、模型质量和资源库。
4. Agent 会由 UI 自动启动；关闭 UI 后索引与搜索服务继续在托盘运行。

本包自带锁定的标准视觉模型和私有 Python/CUDA 运行时。语音与 OCR 模型按选择下载，并逐文件校验 SHA-256。

## 本轮重点

- 搜索可按已配置的资源文件夹过滤，选择会随搜索会话保留。
- 非视觉搜索延迟加载 CLIP，索引运行中执行文件名/语音/OCR 搜索不再额外占用视觉模型显存。
- 资源库预览随网格/列表可见项流式加载，缓存命中不再阻塞后续视频。
- 视觉索引使用多路定位取样、OpenCV/NumPy 并行 CPU 预处理和自适应 CUDA 批处理；OCR 改为批量识别。
- 全速解码并发会同时根据 CPU、可用内存与本地/网络存储类型缩放；状态会报告 `storageType`、批大小与实际并发数。
- 主程序、托盘 Agent、更新程序和在线安装器统一使用用户指定图标。
- 资源文件夹现在可从资源库页或设置页移除。移除只删除应用配置和对应生成索引，绝不会删除原始媒体文件。
- 分组件在线安装器会顺序下载、校验、解压并删除临时包；大模型仍支持按需下载。

- 修复内置播放器关闭时的媒体线程释放竞态；播放器窗口由应用持有并在解绑后延迟释放。
- Agent 命名管道支持并发状态/搜索请求；搜索 Worker 断开或异常输出时自动重启并重试。
- 资源库直接扫描已配置目录，未索引的视频和图片也会立即显示。
- 缺失预览图会使用 Windows 媒体缩略图生成缓存；失效的索引预览路径会自动补偿。
- 自动索引的文件变化、防抖等待、排队和 Worker 启动阶段均显示在索引任务页。
- 正常状态移入页面正文与进度条附近；通知栏只用于故障或功能降级。
- 索引百分比独立显示在进度条右侧。
- 设置更改自动防抖保存，不再需要“保存更改”按钮。
- 新增存储管理，准确统计应用、私有运行时、模型、索引/预览和状态日志占用，并可安全删除重复或未使用的本地模型。
- 修复设置页初始化闪退。
- 新增并默认开启“自动索引新文件”，目录事件经防抖后触发增量扫描。
- 修复 PaddleOCR/PaddleX 运行时兼容与 OCR 模型名称解析，二次运行不再重复已完成的 OCR。
- 索引 ETA 在后端批提交间隔内也会每秒连续倒计时。
- 资源库改为最小差异刷新并缓存缩略图，避免轮询导致整页闪动。
- 搜索查询、结果、来源和网格/列表模式在页面切换后保留。
- 增大资源库网格卡片的文字区域，避免底部状态被裁切。
- 重写左侧导航为 Windows NavigationView 的自然紧凑/展开行为。
- 设置页改为左侧分类、右侧设置卡片，删除集中堆叠的下拉菜单。
- 资源库的网格和列表均显示视频预览、大小、时长与索引状态。
- 搜索结果的网格和列表均显示命中时间点对应的真实渲染预览，可从该时间点播放。
- UI 自动启动并通过当前用户专属命名管道连接 Agent。
- 视觉索引真实使用 CUDA（可用时）、自适应批大小和按机器探测的并行解码器数量。
- 文件名、视觉、语音、OCR 与中文音近候选可融合返回；搜索 Worker 常驻复用模型。
- 设置页可选择并下载锁定的 Whisper/OCR 模型。

## 本轮验收边界

- 已通过 Windows 全量编译门、自动化测试、WinUI 启动健康检查，以及隔离样片的真实 CUDA 索引/准确时间点搜索验证。

- 在线安装器采用应用核心、私有运行时、基础视觉模型和可选 OCR 模型分组件下载，并在 MLCCS 网站按“载荷先、清单最后”发布。
- UI 外观、交互手感、缩放、高对比度、Narrator 与键盘主观验收交给用户反馈。
